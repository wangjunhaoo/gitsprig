# GitSprig v0.1.0

进入 Vibe Coding，留住熟悉的 Git 体验。

用了多年 IntelliJ IDEA、PyCharm、WebStorm，已经习惯 JetBrains 内置的 Git。到了 Vibe Coding 时代，日常编码逐渐转向 AI 工具，却常常为了审阅改动、整理提交，又打开了很重的 IDE。

一直没找到对自己来说同样顺手的独立 Git GUI，所以做了轻枝 GitSprig：让熟悉的 Git 工作方式可以独立运行，和新的编码工具一起使用。

GitSprig 把审阅改动、拆分提交、分支管理和冲突处理放进一个桌面工作区。使用 Tauri + Rust 与系统 WebView，不建立项目代码索引，原创代码采用 MIT 许可证。项目为独立实现，与 JetBrains 无官方关联。

## 这个版本有什么

- 打开、克隆、初始化和切换仓库，记住最近仓库及面板布局。
- 双栏/单栏差异，按文件、代码块和行选择提交，按任务组织变更。
- Shift 多选、范围勾选、右键批量忽略，处理同名文件与精确路径。
- 分支拓扑图、文件历史和逐行追溯；可搜索的本地分支、远程仓库和推送目标。
- 三栏合并、交互式变基、挑选与撤销提交、标签、Stash、工作树和 Reflog 恢复。
- 自定义 OpenAI 兼容接口与模型生成提交说明，配置保存在用户目录，生成后可编辑。

Git 操作沿用系统 SSH、凭据助手、提交钩子和签名。部分提交使用临时索引，并检查已有暂存与外部改动；拉取默认仅快进，强制推送校验远端状态。

## 安装与校验

本版提供 Apple Silicon 的 `GitSprig_0.1.0_aarch64.dmg`，需要 macOS 14 或更新版本及 Git 2.40 以上。打开镜像后将应用拖入 Applications。

`SHA256SUMS.txt` 用于核对附件完整性，`manifest.json` 记录构建版本、架构和包体积。DMG 和应用内均附有 MIT 许可证及第三方声明。构建方法见仓库 README。

默认安装包使用临时签名，**尚未经过 Apple 公证**。首次打开可能显示未验证开发者提示，处理步骤见 [安装说明](INSTALL_MACOS.md)。

## 已知边界

- 完整桌面验证在 Apple Silicon / macOS 26.4.1 上完成；最低目标 macOS 14 尚未完成全部独立实机交互验收。
- Intel Mac、Windows 和 Linux 尚未完成平台验收。
- 当前性能基线的空闲 RSS 合计中位数约 251 MB，低于 200 MB 的目标仍未达到。具体环境与启动测量见 [验收记录](ACCEPTANCE.md)。
- AI 接口已通过本机模拟服务验证，不保证所有第三方供应商的协议差异；使用者自行配置服务及承担可能的模型费用。
