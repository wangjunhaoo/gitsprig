# 轻枝 · GitSprig 项目介绍与分享文案

以下文案用于仓库介绍和发布时分享。文案已经准备好；是否公开发布、发布在哪个平台，由维护者决定。

## 一句话介绍

只想好好用 Git，不必启动整个 IDE。

## 名字的含义

中文名“轻枝”，英文名 GitSprig。“枝”是 Git 分支，“轻”是独立、轻量；Sprig 意为小枝。希望它是一件轻巧、顺手、专注于 Git 的工具。

## GitHub 仓库简介

只想好好用 Git，不必启动整个 IDE。基于 Tauri + Rust 的轻量桌面客户端，支持部分提交、三栏合并和自定义 AI 提交说明。

## 社区分享稿

### 标题

做了一个独立的 Git 客户端：保留顺手的操作体验，把 IDE 留给写代码

### 正文

做 GitSprig 的原因很简单：我很喜欢 JetBrains IDE 里的 Git 体验，变更列表、差异对比、右键菜单和冲突处理都很顺手。

但有时我只是想看看改了什么，挑几行代码提交，或者切个分支，不想为这些操作打开整个 IDE，再等项目加载和索引。代码编辑器已经有了，能不能让 Git 也有一个随时打开就能用的独立工具？

于是有了轻枝 GitSprig。

它把日常 Git 工作放进一个紧凑的窗口：左边整理变更，中间看差异或历史，提交说明就在手边。支持 Shift 连续多选、右键批量忽略，也能搜索远程分支，确认方向后推送。

我尤其在意“这次到底提交了什么”。一个文件里同时改了两件事，可以按代码块或行拆开提交，再按任务分组。已有暂存内容也纳入检查；如果选择与暂存版本重叠冲突，或者文件在外部发生变化，应用会停止并要求重新选择。

遇到复杂一点的工作，也可以继续留在这个窗口里：三栏合并、交互式变基、Stash、工作树、逐行追溯和 Reflog 恢复都有对应入口。

技术上用 Tauri、Rust 和系统 WebView，不建立项目代码索引。底层仍然调用自己的 Git，SSH、凭据助手、钩子和签名配置可以继续使用。

提交说明支持 AI 辅助生成，接口、模型和密钥都由自己配置，兼容 OpenAI 格式，也可以连本地模型。只有主动点击生成时，才发送本次选择的差异及必要上下文；结果可以修改，提交仍由自己决定。

GitSprig 的原创代码采用 MIT 许可证。目前先面向 Apple Silicon Mac；默认安装包尚未经过 Apple 公证，其他平台也还没有完成验收。轻量还有继续优化的空间，性能测量和已知边界都写在仓库里。

如果你也想把 Git 操作从 IDE 里独立出来，欢迎试用，提 Issue，或者一起改进。

## 短分享稿

做了一个独立的 Git 客户端 GitSprig。起因是喜欢 IDE 里的 Git 体验，但只想查看改动、拆分提交时，不想启动整个 IDE。

Tauri + Rust，使用系统 WebView，不建立代码索引。支持按文件/块/行提交、任务分组、双栏差异、三栏合并和分支历史，沿用本机 Git 配置。AI 提交说明可自定义 OpenAI 兼容接口和模型。

原创代码采用 MIT 许可证，目前先支持 Apple Silicon Mac。默认安装包未经过 Apple 公证；性能数据和已知边界见仓库说明。欢迎试用和反馈。

## 文案事实边界

- 项目由熟悉的 IDE Git 使用体验启发，为独立实现，与 JetBrains 无官方关联。
- 当前交付目标为 macOS 14 及以上的 Apple Silicon 设备；其他平台未完成验收。
- 不宣称“零资源占用”“永不丢失改动”或所有机器都能在两秒内启动。
- 安装包大小与性能数字引用对应版本的验收记录，不把 footprint 和 RSS 混为一谈。
- AI 需要使用者配置服务；GitSprig 不提供模型订阅，第三方服务可能收费。
- 源码采用 MIT 许可证不代表安装包已经获得 Apple 签名与公证。
