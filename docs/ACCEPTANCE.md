# 验证与性能记录

本记录汇总 0.1.0 开发阶段在 2026-09-09 完成的本机验证，时区为 Asia/Shanghai。公开仓库保留验证摘要；原始运行日志、临时仓库路径、AI 请求体和本机配置不进入源码仓库。

## 自动化验证

- 44 项独立 Git 仓库工作流测试：部分提交、已有暂存保护、钩子、特殊路径、合并与变基恢复、Stash、工作树、远程推送、忽略规则和 ITA 标记。
- 1 项原始路径字节的忽略规则测试。
- 9 项 AI 接口与文件存储测试：自定义模型、认证、取消、异常响应、配置权限及密钥隔离。
- 15 项前端逻辑测试：差异选择、变更分组、历史图、多选和草稿保护。

Git 与网络测试使用临时仓库和本机模拟服务，没有向真实业务远程推送，也没有使用真实模型密钥。Rust 测试脚本先编译，再按最多 12 项一组运行，每批限制 60 秒。

## 真实桌面验证

已在 Tauri / WKWebView 桌面窗口中验证：

- 打开仓库、双栏差异、按行勾选和实际部分提交，保留其他暂存及工作区内容。
- 三栏合并中的接受单侧、手工编辑、保存与标记解决分离，以及退出后继续操作。
- 交互式变基修改提交说明、中文菜单和快捷键、主题切换、面板调整及重启恢复。
- AI 保存测试密钥、重启读取、生成草稿、手工修改保护、取消及认证失败。
- 1002 个远程分支的搜索与键盘导航、远程切换、新目标分支和非当前分支推送。
- 206 项改动列表的跨页 Shift 多选、范围勾选、右键批量忽略，保护原文件和其他暂存版本。

macOS 文件系统不允许创建包含非法 UTF-8 字节的文件名，因此相应模式转义通过纯逻辑测试验证。含换行的忽略模式无法精确表达时会拒绝写入；子目录反向忽略规则仍生效时会明确提示。

## 性能基线

设备：Apple M4、24 GB 内存、macOS 26.4.1。基准仓库包含 10,000 个文件、50,000 条提交和 200 个改动文件，位于本地 SSD。

启动测量共五轮，每轮启动一个新进程，未清空系统磁盘缓存；在仓库可操作并完成两次绘制回调后记录。每轮静置 30 秒后采样，内存合计主进程及三个 WebKit 进程。

| 指标                   | 基线结果                |
| ---------------------- | ----------------------- |
| 启动中位数 / 最慢      | 0.799 秒 / 0.865 秒     |
| 空闲 footprint 中位数  | 97.390 MB               |
| 空闲 RSS 中位数 / 最高 | 250.937 MB / 256.180 MB |
| 空闲 CPU 样本中位数    | 每轮 0.0%               |

**RSS ≤ 200 MB 的目标尚未达到。** footprint 与 RSS 是不同口径，不能互换，也不能把逐进程相加说成已去重的物理内存。[Apple 内存分析说明](https://developer.apple.com/videos/play/wwdc2021/10180/)

更早的一轮启动曾达到 2.534 秒，因此这些数据不保证所有首次启动均低于两秒。后续小版本功能修正没有重复完整性能测量。

2026-09-09 的开源分发准备将产品名统一为轻枝 GitSprig，补充 MIT 和完整第三方声明后，本机 ARM64 DMG 为 2.914 MB，应用文件合计为 5.426 MB。安装包与许可证资源已校验，默认采用临时签名，未执行 Apple 公证。此处为本地构建记录，不代表 GitHub 上已经发布。

## 已知边界

- 当前实机验证环境为 macOS 26.4.1 / Apple Silicon；最低配置目标为 macOS 14，尚未在独立 macOS 14 设备上完成全部交互验收。
- Intel Mac、Windows 和 Linux 尚未完成平台验收。
- 默认构建使用临时签名，未经过 Apple 公证；开源本身不会消除 macOS 的未验证开发者提示。
- AI 的协议验证使用本机模拟服务，不代表所有第三方模型供应商的接口差异都已验证。
