# macOS 安装说明

GitSprig 当前面向 Apple Silicon Mac，最低系统目标为 macOS 14，需要已安装 Git 2.40 或更新版本。Intel Mac 尚未完成验收。

## 安装

打开 GitSprig 的 DMG，将 GitSprig 拖入 Applications，再从“应用程序”启动。首次运行可选择本地 Git 仓库，或填写远程地址进行克隆。

仓库的 README 提供从源码运行与构建方法。若下载发行包，请使用维护者在项目仓库中发布的附件，并核对随包提供的 SHA256 校验值。

## 为什么 macOS 会提示无法验证开发者

当前默认安装包采用临时签名，尚未使用 Developer ID 签名并完成 Apple 公证。通过网络下载或传给同事后，macOS 可能显示无法验证开发者或无法检查恶意软件的提示。开源本身不会改变系统的这项检查。

如果你已确认来源可信、文件未遭篡改，Apple 提供了针对单个应用的打开方式：先尝试启动一次，再到“系统设置 → 隐私与安全性”，找到该应用对应的“仍要打开”，按提示确认。参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果提示“将损坏你的电脑”或文件已损坏，先停止打开，核对下载来源、校验值和发行版本。此类提示不应直接当成“未验证开发者”处理。

公司管理的设备可能不允许使用该例外，需要联系设备管理员。正式分发时，维护者可通过 Developer ID 签名和 Apple 公证改善首次安装体验；这不要求应用上架 App Store。

## AI 配置

AI 为可选功能，在设置中填写自己的接口地址、模型 ID 和 API Key。配置保存在 `~/.gitgui/ai.json`，不使用钥匙串。文件为明文，macOS 下目录权限为 700、文件权限为 600；分享配置或反馈问题时请删除真实密钥。

只有点击生成时才会向所配置服务发送本次所选差异及必要上下文。生成内容可以编辑，不会自动提交或推送。
